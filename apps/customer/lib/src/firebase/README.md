# Configuración FlutterFire

Los archivos `firebase_options_dev.dart` y `firebase_options_prod.dart` se generan
con los comandos documentados en `docs/stage-17-customer-shell.md`.

tokens, contraseñas, cuentas de servicio ni credenciales de proveedores.
